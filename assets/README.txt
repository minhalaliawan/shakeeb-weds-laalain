Optional files. The site works fine without any of them.

music.mp3   - background music. If you drop a file here it is used instead of
              the online track that is currently playing.
mehndi.jpg  - the printed Mehndi invitation card
barat.jpg   - the printed Barat invitation card
walima.jpg  - the printed Walima invitation card

If one of the three card images is present, a "View Card" button appears on that
event and opens the image full screen. If it is missing, the button is removed
automatically - nothing breaks.
